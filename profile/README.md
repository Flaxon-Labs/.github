# Flaxon Labs

> Building open-source technology for developers.

Flaxon Labs is an independent open-source organization focused on building modern, practical, and developer-friendly software.

We explore ideas across **backend development, web technologies, developer tooling, programming languages, compilers, reactivity, and AI**—with a focus on creating tools that are lightweight, extensible, and enjoyable to use.

## 🚀 What We Build

Our projects can range from small developer utilities to complete frameworks and experimental technologies.

Some areas we work on include:

- 🐍 **Python & Backend** — frameworks, libraries, APIs, and developer tools
- 🌐 **Web Development** — template engines, frontend tooling, and web technologies
- ⚡ **Reactivity** — lightweight reactive systems and state management
- 🔧 **Developer Tools** — CLIs, compilers, build tools, and development utilities
- 🧠 **AI & Machine Learning** — experiments and tools for developer-focused AI
- 🧪 **Experimental Technology** — new ideas, prototypes, and research-driven projects

## 📦 Projects

Flaxon Labs is home to projects such as:

### Flaxon
An async-first Python backend framework designed to provide a simple and modern developer experience.

### Teloce
A lightweight reactive template engine designed to bring modern reactive development to Python-based web applications.

### Teloce-Py
Python tooling and compiler infrastructure for the Teloce ecosystem.

### Tiny Reactive
A lightweight reactive system focused on signals, state, and efficient updates.

> These are only some of the projects within Flaxon Labs. The organization may grow to include new technologies and experiments over time.

## 🎯 Our Philosophy

We believe developer tools should be:

- **Simple** — easy to understand and get started with
- **Powerful** — capable of handling real-world applications
- **Lightweight** — avoid unnecessary complexity
- **Extensible** — designed to grow with developers and communities
- **Open** — built openly and shared with the community
- **Practical** — solve real problems rather than adding complexity for its own sake
